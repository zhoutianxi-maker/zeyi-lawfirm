# 泽仪律师事务所 · 官方网站

全新官网前端项目，纯 HTML + CSS + JavaScript 静态站点，无需构建工具，直接部署即可上线。

## 预览方式

双击打开 `index.html` 即可浏览（首屏视频、字体 CDN 需要联网）。
或在项目目录启动任意静态服务器：

```bash
npx serve .
# 或
python -m http.server 8080
```

## 设计说明

- **主色调**：品牌深蓝 `#004090`、深海军蓝 `#0A2E5C / #061A30`、灰阶辅助，符合「蓝色 + 灰色」的定位
- **字体**：标题使用思源宋体（Noto Serif SC，jsdelivr CDN 加载，断网自动回退系统宋体），正文使用系统黑体栈
- **风格**：大留白、细线分隔、毛玻璃导航、入场滚动动画、数字滚动，参考京师、中伦等一线律所官网的庄重格调
- **响应式**：桌面（1200px 容器）、平板（960px）、手机（640px）三档断点；移动端抽屉菜单、单列布局、隐藏首屏视频以省流量
